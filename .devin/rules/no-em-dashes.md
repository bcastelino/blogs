---
name: No em dashes
description: Avoid the em dash character in code, docs, blog posts, and other project files.
---

Do not use the em dash character (`U+2014`, `&mdash;`, `—`) anywhere in this project unless its presence is mandatory (for example, when documenting this rule or referring to the Unicode code point).

This applies to:

- code and comments
- documentation and README
- blog posts and content
- any other project file

When an em dash would be natural, use one of these instead:

- a comma
- a semicolon
- a colon
- a hyphen (`-`)
- parentheses
